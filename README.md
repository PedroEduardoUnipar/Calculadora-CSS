# CalculadoraCSS

Projeto Angular desenvolvido para praticar componentes, formulários e estilização com CSS.

## Funcionalidades

- Calculadora de troco
- Cálculo de preço por quilo
- Interface responsiva com cards

## Tecnologias

- Angular 19
- TypeScript
- HTML
- CSS

## Executar o projeto

```bash
npm install
npm start
```

Depois, acesse `http://localhost:4200/`.
