# Calculadora CSS

Projeto acadêmico desenvolvido em Angular para praticar componentes, formulários, lógica em TypeScript e estilização com CSS.

## Funcionalidades

- cálculo de troco
- cálculo de preço por quilo
- exibição dos resultados na interface
- organização visual em cards
- layout responsivo

## Tecnologias

- Angular 19
- TypeScript
- HTML
- CSS

## Estrutura principal

- `src/` — código da aplicação
- `public/` — arquivos públicos
- `angular.json` — configuração do Angular
- `package.json` — dependências e scripts do projeto

## Como executar

```bash
npm install
npm start
```

Depois, acesse:

```text
http://localhost:4200/
```

## Objetivo acadêmico

O projeto foi desenvolvido para exercitar a criação de interfaces com Angular, manipulação de dados de formulário, lógica de cálculo e aplicação de estilos com CSS.
